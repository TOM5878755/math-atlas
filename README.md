# Math Atlas · 数学群星图

一个使用 Three.js 构建的 3D 数学知识宇宙。可旋转、缩放、搜索并点击 286 个知识恒星，探索数学分科的层级和简介。

## 本地预览

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 <http://localhost:4173>。

## 项目结构

- `dist/index.html`：页面结构
- `dist/styles.css`：视觉样式与响应式布局
- `dist/app.js`：Three.js 三维场景、交互、飞行和搜索
- `dist/atlas-data.js`：数学知识分类与简介数据
